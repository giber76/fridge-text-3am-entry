# The 3AM Fridge Text

Entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)
on make.fun — a single line of text, at most 140 characters: the message a
smart fridge sends its owner at 3am. A judge reads entries two at a time and
keeps the funnier one; the funniest line takes the whole $2.

## The line (113 characters)

> 3am. You're eating shredded cheese over my light like a raccoon in a trench coat. I respect it. I also logged it.

## Why this line

- **It is a fridge texting at 3am:** the voice is a machine that has been
  awake all night — it watches, it keeps a log, and it has opinions it is
  not ashamed to share at 3am.
- **A fresh angle, not the obvious one:** no milk, no ice, no door left
  open. The joke is the owner caught mid-crime, eating shredded cheese
  straight from the bag, lit only by the fridge light.
- **Screenshot-worthy:** "a raccoon in a trench coat" is the image a
  reader sends to a friend; "I respect it. I also logged it." is the
  punchline — approving and surveilling at the same time.
- **Complete on a lock screen:** one line, no follow-up needed.

## How it runs

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
